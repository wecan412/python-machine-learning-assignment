## Project Description
This repository contains two practical machine learning projects developed in Python using Scikit-learn and Matplotlib. 

1. **Supervised Machine Learning:** A Linear Regression model built to predict student examination scores based on study metrics.
2. **Unsupervised Machine Learning:** A K-Means Clustering model used to group customers based on their shopping behaviour.
